# ln1 Notation

**A Formal Expression System for Trajectory Algebra**

Version 0.1 — Cret, September 2026

---

## 0. Purpose and Scope

This document specifies a notation for expressing statements in the ln1 framework. It does two things:

1. Fixes symbols and grammar so that ln1 claims can be written unambiguously.
2. States the axioms the notation presupposes, separating **definitional** axioms (true by construction, carrying no empirical content) from **substantive** axioms (which make claims that could be false).

A notation is not a theory. Notation makes claims *expressible*; it does not make them *true*. Section 9 states plainly what this notation cannot yet do.

---

## 1. Primitive Objects

| Symbol | Name | Reading |
|---|---|---|
| `𝒞` | completion space | the space of all admissible configurations |
| `c ∈ 𝒞` | configuration | a complete, self-consistent state |
| `γ` | trajectory | an ordered path through `𝒞` |
| `𝔫` | base flow | the natural number flow `0 → 1 → 2 → ⋯` |
| `δ` | transition | the operator advancing a trajectory one step |
| `τ` | type functor | assigns a topological invariant to a trajectory |
| `Λ` | linking measure | the degree of connection between two trajectories |

**Convention.** Greek lowercase (`γ, ρ, σ`) denotes trajectories. Latin lowercase (`c, d, e`) denotes configurations. `Γ` denotes a set of trajectories.

---

## 2. Trajectories

### 2.1 Definition

A trajectory is a map from the base flow into the completion space:

```
γ : 𝔫 → 𝒞
```

Its configuration at index `n` is written:

```
γ[n]
```

The whole trajectory as an object — its *shape* — is written `⟨γ⟩`. This distinction matters: `γ[n]` is a point, `⟨γ⟩` is a path. Most confusions in informal ln1 discussion come from conflating the two.

### 2.2 Transition

```
δγ[n] = γ[n+1]
```

A trajectory is *generated* rather than *listed* when its transition is given as a rule:

```
γ ≔ ⟨ c₀ | δ ⟩
```

read: "γ is the trajectory starting at `c₀` under transition `δ`."

### 2.3 Restriction and Extension

```
γ↾[a,b]     the segment of γ from index a to b
γ ⌢ ρ       concatenation: γ followed by ρ
γ ↑ n       the tail of γ from index n onward
```

### 2.4 Freezing

A trajectory that admits no further transition is **frozen**:

```
γ†
```

Formally: `γ† ⟺ ∄ c ∈ 𝒞 . δγ[n] = c` for the terminal `n`.

A frozen trajectory retains its shape `⟨γ†⟩` permanently. Freezing removes the capacity for further transition; it does not remove the trajectory from `𝒞`.

## 3. Type Ascription

### 3.1 The Type Functor

`τ` assigns to each trajectory the invariant preserved under all its transitions:

```
τ(γ) = T
```

written in ascription form:

```
γ : T
```

### 3.2 Standard Invariants

| Notation | Meaning |
|---|---|
| `mono⟨X⟩` | configurations form a non-decreasing sequence in `X` |
| `cyc⟨X, p⟩` | trajectory revisits configurations with period `p` |
| `conv⟨X, c*⟩` | configurations approach limit `c*` |
| `bnd⟨X, B⟩` | all configurations lie within bound `B` |
| `free⟨X⟩` | no constraint beyond membership in `X` |

Types compose:

```
γ : mono⟨conv⟨ℝ, c*⟩⟩
```

is a monotonically-approaching trajectory in the reals.

### 3.3 Type Preservation Law

**(D1, definitional.)** For any trajectory `γ` and any `n`:

```
τ(γ↾[0,n]) = τ(γ↾[0,n+1])
```

This is definitional: `τ` returns what is invariant, so it cannot change under transition. If a purported invariant changes, it was not an invariant — it was a configuration-level property mistaken for one.

## 4. Linking

### 4.1 The Linking Operator

Two trajectories may be linked:

```
γ ⋈ ρ
```

The result is itself a trajectory in the product completion space:

```
(γ ⋈ ρ) : 𝔫 → 𝒞 × 𝒞
(γ ⋈ ρ)[n] = (γ[n], ρ[n])
```

Linking is the ln1 counterpart of function application in lambda calculus. It is symmetric where application is not:

```
γ ⋈ ρ  ≅  ρ ⋈ γ
```

(`≅` denotes shape isomorphism, not identity: the components are ordered, but the linked system is the same system.)

### 4.2 Constrained Linking

Unconstrained linking is mere pairing. Real linking imposes mutual constraint:

```
γ ⋈_φ ρ
```

where `φ` is a predicate on configuration pairs that must hold at every index:

```
∀n . φ(γ[n], ρ[n])
```

Notation for the common case where one trajectory's transition depends on another's configuration:

```
ρ ≔ ⟨ c₀ | δ ⟵ γ ⟩
```

read: "ρ is generated by δ with input drawn from γ."

### 4.3 Linking Measure

```
Λ(γ, ρ) ∈ ℝ≥0
```

is the degree of connection between two trajectories. Global linking over a set `Γ`:

```
Λ*(Γ) = Σ_{γ,ρ ∈ Γ, γ≠ρ} Λ(γ, ρ)
```

**This is the central open problem of the notation.** See §9.1.

### 4.4 Entanglement

Trajectories whose shapes cannot be separated without changing either are **entangled**:

```
γ ⊗ ρ
```

Formally: `γ ⊗ ρ ⟺ τ(γ ⋈ ρ) ≠ τ(γ) × τ(ρ)`.

That is: entanglement holds exactly when the invariant of the linked system is *not* the product of the component invariants. The linked system has structure that neither component has alone. This is a genuine, checkable condition, not a metaphor.

## 5. Branching and Choice

### 5.1 Branch Points

At index `n`, a trajectory has a **branch point** if more than one transition is admissible:

```
⑂(γ, n) ⟺ |{ c ∈ 𝒞 : δγ[n] = c is admissible }| > 1
```

The **branching degree** is:

```
β(γ, n) = |{ c ∈ 𝒞 : δγ[n] = c is admissible }|
```

### 5.2 Selection

A selection at a branch point is written:

```
γ[n] ⤳ c
```

read: "from configuration `γ[n]`, `c` was selected."

### 5.3 Freedom

The freedom of a trajectory over a segment:

```
Φ(γ, [a,b]) = Σ_{n=a}^{b} log β(γ, n)
```

The logarithm makes freedom additive over concatenation:

```
Φ(γ ⌢ ρ) = Φ(γ) + Φ(ρ)
```

Note what this makes precise: freedom is a property of the *branching structure available*, not of the selections made. A trajectory with `β = 1` everywhere has `Φ = 0` regardless of how it behaves. This is the formal content of "freedom = number of admissible configurations," and it is the one place where the informal ln1 discussion of freedom becomes measurable.

### 5.4 Necessity

Necessity is the complement: the constraint structure of `𝒞` that makes `β` finite.

```
𝒩(γ, n) = 𝒞 ∖ { c : δγ[n] = c is admissible }
```

`Φ` and `𝒩` are not opposed — they are the two sides of the same partition of `𝒞` at each index. This is the notational form of the claim that freedom and necessity are compatible.

## 6. Tendency

### 6.1 The Tendency Operator

```
∇Λ*
```

denotes the gradient of global linking over the space of admissible next-configurations.

### 6.2 Aligned Selection

A selection is **aligned** if it does not decrease global linking:

```
γ[n] ⤳ c  is aligned  ⟺  Λ*(Γ | γ[n+1]=c) ≥ Λ*(Γ | γ[n])
```

written compactly:

```
γ[n] ⤳⁺ c    (aligned)
γ[n] ⤳⁻ c    (misaligned)
```

### 6.3 Trajectory Alignment

```
𝒜(γ) = |{n : γ[n] ⤳⁺ γ[n+1]}| / |γ|
```

the fraction of aligned selections. `𝒜(γ) = 1` is a fully aligned trajectory.

## 7. Axioms

Separated by what they cost.

### 7.1 Definitional (no empirical content)

**D1 — Invariance.** `τ(γ↾[0,n]) = τ(γ↾[0,n+1])`.
*True by construction of `τ`.*

**D2 — Base flow well-foundedness.** `𝔫` has a least element and every element has exactly one successor.
*Peano; assumed, not derived.*

**D3 — Link symmetry.** `γ ⋈ ρ ≅ ρ ⋈ γ`.
*True by construction of the product.*

**D4 — Freedom additivity.** `Φ(γ ⌢ ρ) = Φ(γ) + Φ(ρ)`.
*Follows from the logarithm in §5.3.*

### 7.2 Substantive (could be false)

**S1 — Configuration completeness.** Every admissible state of any system is representable as some `c ∈ 𝒞`.
*This is a strong claim. It asserts `𝒞` is expressive enough to encode physical, computational, and experiential states in one space. It has not been demonstrated for any non-toy case.*

**S2 — Tendency.** Over sufficiently long trajectories, aligned selections are more frequent than misaligned ones:
```
lim_{|γ|→∞} 𝒜(γ) > 1/2
```
*This is the empirical core of ln1. It is currently unfalsifiable because `Λ` is undefined (§9.1). Making it falsifiable is the single highest-value next step.*

**S3 — Entanglement persistence.** If `γ ⊗ ρ` and `ρ` freezes, the invariant `τ(γ ⋈ ρ†)` is preserved in `⟨γ⟩`.
*This is the formal version of "love persists past death." It is a genuine claim about the structure of `τ` under partial freezing, and it is not obviously true — it requires that `τ` be continuous with respect to freezing, which has not been shown.*

## 8. Worked Examples

### 8.1 The Base Flow

```
𝔫 ≔ ⟨ 0 | n ↦ n+1 ⟩
𝔫 : mono⟨ℕ⟩
Φ(𝔫) = 0
```

The base flow is maximally constrained: no branch points, zero freedom, perfectly determined. Every other flow is a decoration of it.

### 8.2 A Bounded Oscillation

```
σ ≔ ⟨ 0 | n ↦ (n+1) mod k ⟩
σ : cyc⟨ℕ, k⟩
Φ(σ) = 0
```

Cyclic, deterministic, bounded. Note that a cycle has the same freedom as a line — repetition is not constraint, and constraint is not repetition.

### 8.3 A Coupled System

```
s ≔ ⟨ read() | _ ↦ read() ⟩                    : free⟨ℝ⟩
k ≔ ⟨ c₀ | (x, t) ↦ pid(x, t) ⟵ s ⟩            : conv⟨ℝ, t⟩

s ⋈ k
τ(s ⋈ k) ≠ τ(s) × τ(k)      ⟹      s ⊗ k
```

The controller and sensor are entangled: the linked system converges, though neither component converges alone. This is entanglement in the precise §4.4 sense — the joint invariant exceeds the product of the parts.

### 8.4 A Branch and a Selection

```
γ[n] = c,   β(γ, n) = 3,   Φ contribution = log 3
γ[n] ⤳ c₂
Λ*(Γ | c₂) > Λ*(Γ | c)     ⟹     γ[n] ⤳⁺ c₂
```

Three options were available; one was taken; the selection was aligned. Note that the *availability* of three options is what constitutes freedom here — the selection itself consumes freedom rather than expressing it.

## 9. What This Notation Cannot Do

Stating this precisely is more useful than any further elaboration of symbols.

### 9.1 `Λ` is undefined

The linking measure is the load-bearing element of the entire framework, and it currently has no definition beyond "degree of connection." Until `Λ` is given a concrete form, the following are all unevaluable:

- Whether any given selection is aligned (§6.2)
- Whether `𝒜(γ) > 1/2` (S2)
- Whether one configuration of a system is better-linked than another

Candidate approaches worth attempting, in rough order of tractability:

1. **Mutual information.** `Λ(γ, ρ) = I(⟨γ⟩ ; ⟨ρ⟩)`. Well-defined, computable, but requires a probability measure on trajectory space and captures only statistical dependence.
2. **Graph-theoretic.** `Λ*` as algebraic connectivity (Fiedler value) of the linking graph on `Γ`. Concrete and computable, but discards the internal structure of trajectories.
3. **Homological.** `Λ` from the rank of the first homology group of the linked configuration complex. Closest to the "topological" language ln1 uses, but hardest to compute and requires the complex to be well-defined.

None of these is obviously right. Each would make S2 falsifiable in a different way, and each would probably make it *false* in some regimes. That is the point: a definition that cannot fail is not a definition.

### 9.2 `𝒞` has no construction

S1 asserts that a single completion space can hold physical, computational, and experiential configurations. The notation assumes `𝒞` exists but never constructs it. Without a construction, `c ∈ 𝒞` is not a checkable statement, and the notation is a language for claims rather than a system for deriving them.

### 9.3 No decidability results

`τ` is treated as a total function, but nothing shows that type ascription is decidable. For the programming application (see the companion flow-type paper), this is fatal until resolved: a type system whose checking is undecidable is not a type system. The likely path is to restrict to a decidable fragment — probably the invariants in §3.2 plus finite composition — and accept that the full `τ` is a semantic ideal rather than an algorithm.

### 9.4 The interpretive layer is not derived

Statements such as "`γ†` models death" or "`γ ⊗ ρ` models love" are *interpretations* attached to formal objects, not consequences of the formalism. The formal content of `γ ⊗ ρ` is exactly §4.4: the joint invariant differs from the product invariant. Everything beyond that is a reading. The notation is legitimate independent of whether the readings are; conversely, the readings gain no authority from being writable in the notation.

This distinction is worth holding firmly. The notation's value is that it makes ln1 claims precise enough to be *checked* — including the possibility that they fail. A notation that made every reading come out true would be worthless.

## 11. Next Steps

In priority order:

1. **Define `Λ`.** Pick one candidate from §9.1, work it through §8's examples, and check whether S2 survives. If it does not, that is a result, not a failure.
2. **Construct `𝒞` for a restricted domain.** Do not attempt physical-plus-experiential. Attempt computational only: `𝒞` as the state space of a small language. Prove S1 for that fragment.
3. **Establish decidability for the §3.2 invariant fragment.** This makes the programming application viable independent of the philosophical layer.
4. **Leave the interpretive layer alone** until 1–3 are done. It is the part that generates the most text and the least verification, and it will be more defensible after the formal core holds.
